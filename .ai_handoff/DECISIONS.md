# Decisions

- Repository uses three study directories rather than merging their source modules: historical hashes, local dependencies and reproducibility remain intact.
- Keep historical datasets/checkpoints tracked: requested repository is a recoverable scientific record. Exclude runtime environments, smoke/partial scratch outputs and duplicate distribution ZIPs. Largest imported files are below GitHub's per-file limit.
- Preserve archive-native terminology: edge/corner/ring; TinyCNN/TwoLayerCNN; template_init and explicit retention conditions.
- Corrected bank rank10, not full rank. Spectrum controls preserve Fourier magnitude, Gram and singular values initially; this does not imply absence of semantics.
- Add random_unitnorm to release comparison because normalization explains part of the early advantage.
- Release experiment uses fresh block IDs and a fixed longer horizon; does not assume convergence. Fixed validation-only unit selection and matched interventions retained.
- No license selected: original input ownership/license should be reviewed by owner.
- Handoffs are concise topic files, not duplicated full reports; update stale statements instead of accumulating transcripts.
